# Aarogya Sathi

Your Health Companion — a comprehensive healthcare application.

This repo holds all code and development related to our MVP Aarogya Sathi.

## Tech Stack

| Layer    | Technology |
|----------|------------|
| Frontend | Flutter    |
| Backend  | Python     |
| CI/CD    | Jenkins    |

## Project Structure

```
Aarogya Sathi/

```

## Branch Strategy

| Branch       | Purpose                              |
|--------------|--------------------------------------|
| `main`       | Production-ready, stable code        |
| `develop`    | Integration branch for features      |
| `feature/*`  | Individual feature branches          |
| `bugfix/*`   | Bug fix branches                     |
| `release/*`  | Release preparation                  |
